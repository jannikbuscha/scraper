## 2. Collection policy (all sources)

- **Robots.txt** is obeyed. **Default throttling** is about 1 request per second per host; the Wayback Machine gets 1 request per 5 s; a robots.txt `Crawl-delay` above that is honoured (data.gov.ua: 10 s). Backoff on 429/5xx honours `Retry-After`.
- **User-Agent:** `MDT-Portfolio-Research/<version> (+<repository URL>; mailto:<CONTACT_EMAIL from .env>)`.
- **No circumvention:** no CAPTCHA solving, no proxy rotation, no faked browser fingerprints. If a source blocks: the run is marked `partial`, logged and reported, and the collector falls back to the Wayback Machine only where configured. Wayback copies are never used to read paths that the live site's robots.txt disallows (proposed default, §5).
- **Conditional requests** (ETag/Last-Modified) where the host sends them (storage.thedigital.gov.ua, the guide registers, static microsites); most HTML pages send neither, so change detection uses normalised content hashes. Every response is stored unchanged as a raw snapshot (sha256, timestamp, HTTP status).
- **Licence per source** is recorded here and in `sources.yaml`. Releases contain full texts only from openly licensed sources (see `PLAN.md` §6.7).
- **Requirements for the Phase 2 `PoliteHttpClient` found in Phase 0b [0b]:**
  - robots.txt per RFC 9309 (longest match, `*` and `$` wildcards): `urllib.robotparser` applies the first matching rule, so osvita.diia.gov.ua's leading `Allow: /` would wrongly allow `/programmes` (`fixtures/polite_client/robots_osvita_allow_first.txt`);
  - request robots.txt with a neutral `Accept` header: osvita.diia.gov.ua answered `Accept: text/plain` with HTTP 406 (`fixtures/polite_client/robots_osvita_406.txt`), and a 4xx must not silently become "allow all" when the real file exists;
  - re-check robots.txt for **every redirect hop**: the Phase 0b fetcher followed `https://www.kmu.gov.ua/news` → 302 → `/timeline?&type=posts` (robots-disallowed) once; that response is not used anywhere. Count every hop against the per-host interval as well: the fetcher followed its 9 redirect hops at once, 6 of them to the same host less than 1 s after the redirect response;
  - honour Disallow lines of a robots.txt without any `User-agent` line conservatively (playcity.gov.ua), and treat an HTML page served as robots.txt (plan2.diia.gov.ua) as "no robots.txt";
  - a robots.txt answered by a challenge page (codeua.com, Cloudflare) or an edge 403 (www.undp.org, Akamai) means "blocked": stop, no retries (also when the challenge comes with a retryable status such as 503);
  - www.kmu.gov.ua runs the Radware (ShieldSquare) bot manager: every page configures `validate.perfdrive.com` as its challenge (captcha) host [live, 2026-10-30: the 5 kmu news pages of the integration smoke run (22:35Z) embed `ssConf("cu", "validate.perfdrive.com, ssc")` and the `__uzdbm` token]; no challenge was served so far. A redirect to `*.perfdrive.com` (or a page titled with the vendor's name) is a challenge: the client blocks www.kmu.gov.ua without requesting the challenge host (`docs/COLLECTORS.md` §4.7);
  - never follow `/cdn-cgi/…` links or links marked `rel=nofollow` + `aria-hidden` (hidden Cloudflare trap links on usf.com.ua, center.diia.gov.ua, se.diia.gov.ua; e-mail protection links on u24.gov.ua);
  - detect soft 404s by content (usf.com.ua answers 200 "Post not found"; u24.gov.ua answers unknown paths with the app shell);
  - normalise hosts (strip a trailing dot; keep slug case: `/services/RD4U` exists only in upper case);
  - size limit of at least 25 MB per response (guide register JSON 18.5 MB);
  - change detection on normalised content: CSP nonces (thedigital.gov.ua, digitalstate.gov.ua, www.kmu.gov.ua), csrf tokens and the bot-manager script (www.kmu.gov.ua), Telegram `data-view` attributes and relative times (`publishedAt.related`, e.g. "3 тижні тому") change on every request;
  - snapshots that leave the server (exports, fixtures) must not carry client-identifying tokens: the kmu.gov.ua bot-manager token `__uzdbm_2` is base64 of `<UUID-like id>$<IPv4 address>` in all 11 captured kmu pages; the addresses (10 distinct values in one /16 network, among them the development environment's egress address) are those of the requesting client.
